# {{projectName}} — Cursor Rules

Always read AGENTS.md before making changes.

## Five-Artifact Rule
Every UI component change must produce:
1. Component (.tsx)
2. Unit test (.test.tsx) — Vitest + Testing Library
3. Story (.stories.tsx) — Storybook
4. E2E test (e2e/*.spec.ts) — Playwright
5. Screenshot (auto-generated by Playwright)

Non-component code: source + unit test minimum.

## Testing Patterns
- Renderer tests: @testing-library/react (render, screen, userEvent)
- Main process tests: mock electron, test pure functions
- E2E: _electron.launch({ args: ['.'] })
- Always build before E2E: npm run build && npm run test:e2e

## Commands
- npm run test — unit tests
- npm run test:e2e — E2E tests
- npm run lint — ESLint
- npm run format:check — Biome
- npm run test:colocate — verify test co-location

## Conventions
- Strict TypeScript, no any
- Conventional commits (feat:, fix:, chore:)
- IPC: domain:action naming
- Co-located tests next to source files
